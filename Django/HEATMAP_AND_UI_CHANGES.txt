Changes in this build

- DINOv2 heatmap now targets the final transformer's norm1 layer before attention, which preserves spatial patch gradients for Transformer Grad-CAM.
- Heatmap display uses 5th-97th percentile contrast normalisation, gamma expansion, and stronger overlay opacity so meaningful regions are easier to see.
- Input-gradient saliency remains an automatic fallback if Transformer Grad-CAM cannot be produced.
- The Scan Image button is now beside the Analyse a Leaf heading, matching the Scan Another Photo button position on the result page.
- The About page and navigation item were removed.
- The Why it matters section was removed from the home page.

2026-09-28 update
-----------------
- Local `python manage.py runserver` now enables local DEBUG automatically.
- WhiteNoise middleware/manifest storage are used only when DEBUG is off, so
  local development no longer requires a pre-existing `staticfiles/` folder.
- Docker/production `collectstatic` behavior is unchanged and still uses
  WhiteNoise manifest storage.
- DINOv2 explainability now uses class-specific patch attribution rather than
  painting the entire image with a CNN-style Grad-CAM map.
- Only roughly the top 30% of influential regions are displayed.
- The existing rembg foreground mask is reused when reliable to reduce
  background foliage/sky influence in the displayed overlay.
- Result-page wording now labels the method as DINOv2 patch attribution and
  clarifies that the overlay is not an exact disease-segmentation mask.
